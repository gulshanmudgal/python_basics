# Python Fundamentals

A comprehensive collection of Python basics tutorials with interactive examples and detailed notes.

## 📚 Topics Covered

This repository covers fundamental Python concepts through practical examples:

1. **[Strings](Session_01_Strings.py)** - String manipulation, formatting, and operations
   - [📝 Notes](notes/01_strings.md)

2. **[Numbers](Session_02_Numbers.py)** - Arithmetic operations, type casting, and built-in functions
   - [📝 Notes](notes/02_numbers.md)

3. **[Lists, Tuples, and Sets](Session_03_List.py)** - Collection data types and their operations
   - [📝 Notes](notes/03_list.md)

4. **[Dictionaries](Session_04_Dictionaries.py)** - Key-value data structures
   - [📝 Notes](notes/04_dictionaries.md)

5. **[Conditionals](Session_05_Conditionals.py)** - If/elif/else statements and logical operators
   - [📝 Notes](notes/05_conditionals.md)

6. **[Loops](Session_06_Loops.py)** - For loops and iteration
   - [📝 Notes](notes/06_loops.md)

7. **[Functions](Session_07_Function.py)** - Defining and using functions with parameters
   - [📝 Notes](notes/07_function.md)

8. **[Modules](Session_08_Modules.py)** - Importing and creating modules
   - [📝 Notes](notes/08_modules.md)

## 🚀 Getting Started

### Prerequisites
- Python 3.6 or higher
- Basic understanding of programming concepts

### Running the Examples

Each session file can be run directly with Python:

```bash
python Session_01_Strings.py
python Session_02_Numbers.py
# ... and so on
```

The `mymodule.py` file is used by `Session_08_Modules.py` for demonstrating module imports.
